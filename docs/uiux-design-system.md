# UI/UXデザインシステム

## 検索中心型UIの設計

### 検索中心のUI
- ヒーローエリアに検索バー中央配置
- クイックリンク（人気キーワード）
- エリア（産地）ベースの探索導線

### カード型レイアウト
- サムネ + 商品名 + 産地 + 評価 + 価格
- 角丸+シャドウ、ホバーで浮き上がり
- PC: 2-4カラム、スマホ: 2カラム

### 昆布サイトへの適用
- 産地別検索（利尻/羅臼/日高/真昆布）
- ユーザーレビュー（食べ比べ記録）
- お気に入り機能

## 記事・ランキングページの設計

### 記事構成（最重要）
- **結論ファーストは逆効果**（CVR大幅悪化の実験結果あり）
- 「選び方」→「検証方法」→「ランキング」→「比較表」の順序厳守
- 納得感を醸成してからCTAを見せる

### スコア体系
- 5点満点 x 複数軸（旨味/香り/コスパ/使いやすさ）
- 横棒グラフで視覚化

### アフィリエイトリンク
- Amazon(オレンジ) / 楽天(赤) 横並び
- 商品詳細の下に配置（衝動買いではなく納得購入）

### SEO戦略
- **専門特化が有利**: Googleが横断型サイトの評価を下げ、専門特化サイトを優遇する傾向
- E-E-A-T: 専門家監修、独自検証、定期更新
- 構造化データ: Product, Article, BreadcrumbList, FAQPage, Recipe
- タイトルに年月明記で鮮度アピール

## 昆布サイト統合デザインシステム

### カラーパレット（昆布+海テーマ）
| 役割 | 色 | 用途 |
|------|-----|------|
| Primary | `#1b4332` (深い海の緑) | ヘッダー、ヒーロー |
| Primary Light | `#2d6a4f` (昆布グリーン) | ボタン、アクセント |
| Secondary | `#52b788` (海の浅瀬) | タグ、ラベル、リンク |
| Accent | `#d4a373` (出汁の琥珀) | スコア、ハイライト |
| Surface | `#d8f3dc` (薄緑) | バッジ背景、hover |
| BG Light | `#f8faf8` (和紙風) | セクション背景 |
| Text | `#1a1a1a` | 本文 |
| Text Sub | `#6b7280` | サブテキスト |
| Amazon | `#ff9900` | Amazon CTA |
| Rakuten | `#bf0000` | 楽天 CTA |

### タイポグラフィ
- 本文: Noto Sans JP 400/500, 15-16px
- 見出し: Noto Sans JP 700, 18-24px
- 余白: セクション間 40-48px、カード間 12-16px

### コンポーネント設計
- **ProductCard**: 画像(aspect-square) + カテゴリバッジ + 商品名 + ブランド + 価格 + スコア + 産地
- **SearchForm**: テキスト入力 + カテゴリselect + ソートselect + 検索ボタン
- **ShopCTA**: Amazon/楽天の2ボタン横並び
- **カテゴリタブ**: 横スクロールのピル型タブ（sticky）
