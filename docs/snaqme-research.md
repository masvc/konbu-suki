# スナックミー（snaq.me）D2Cモデル分析

## ビジネスモデル
- D2Cサブスクリプション型おやつ宅配。「お菓子ではなくおやつ体験を売る」
- ギルトフリー（人工添加物・白砂糖・水素添加油脂不使用）× サブスク（Tech）× コミュニティ
- 累計資金調達 約11.5億円

## サブスク仕組み
- **月額2,210円**（1,880円+送料330円）、食べきりサイズ8種
- 2週に1回 or 4週に1回、ネコポス配送
- 最低利用期間なし、いつでもスキップ・解約可能

## パーソナライゼーション
1. 初回「おやつ診断」で好み・アレルギーを回答
2. AIが100種類以上から最適8種を選定（1,000億通りの組み合わせ）
3. 届いたおやつを4段階評価（苦手/普通/好き/大好き）
4. 累計5,000万件超のデータでAIが学習→次回BOXに反映
5. **あえて100%パーソナライズにしない**：「意外な出会い」を意図的に組み込む

## 開封体験設計
- **BOXデザイン**: 毎月変わる
- **同梱冊子『3PMmm…』**: 生産者ストーリー、おやつの豆知識
- **撮影用シート**: SNS投稿用の背景シート同梱
- **すごろく**: BOX内側に印刷、家族で楽しめる遊び心

## 生産者関係
- 全国150社以上と「おやつ共創パートナー」関係
- スナックミーが企画・データ提供、パートナーが製造
- 最短約3週間でオリジナル商品を共同開発
- 自社工場・社内工房「スナックミーキッチン」も保有

## マーケティング
- **UGC重視**: 画像付きSNS投稿数を毎日計測、満足度KPIとしても活用
- LINE広告でCV 8.4倍増の実績
- 2022年 清澄白河に初の直営店
- 丸井グループ連携で全国500店舗目標

## 収益モデル
- 個人サブスク + 法人向け福利厚生（snaq.me office）+ EC・店舗 + ギフト事業
- 月次成長率5-10%維持

## こんぶBOXへの応用

### サービスコンセプト
「こんぶ体験BOX」— 昆布という「素材」ではなく「昆布のある食卓体験」を売る

### 商品設計
| 項目 | 内容 |
|------|------|
| 内容 | 食べきりサイズの昆布商品 6-8種 |
| 商品例 | だし昆布（産地違い）、おやつ昆布、佃煮、昆布茶、とろろ昆布、レシピカード |
| 月額 | 2,500-3,000円（送料込み） |
| 頻度 | 月1回 |
| コース | 「だし派」「おやつ派」「料理派」「おまかせ」 |

### 応用ポイント
1. **こんぶ診断**: 味の好み、用途、家族構成、料理頻度で診断
2. **フィードバックループ**: 4段階評価→次回BOXに反映+生産者フィードバック
3. **開封体験**: 季節ごとの産地風景BOX、同梱冊子「KONBU LIFE」、レシピカード
4. **UGCマーケ**: #こんぶ体験 #konbusuki、昆布料理写真の投稿促進
5. **季節限定フォーチュンBOX**: 年4回、5,000-8,000円のスペシャルBOX

### フェーズ
- Phase 1: 個人サブスク開始、月100-500BOX
- Phase 2: コース分化、法人向け「オフィス昆布」
- Phase 3: AI本格導入、ギフトBOX、百貨店展開
- Phase 4: 海外展開（UMAMIブーム活用）
