# 夜間実行の記録

`scripts/night-run.ts` が枠ごとに出力をここへ残す。1晩につき1フォルダ。

```
docs/night/YYYY-MM-DD/
  analysis.md        23:00 分析のまとめ。「伸びしろのある記事トップ10」を含む
  ai-citation.md     AI検索で引用されているか（+ .json）
  improve-log.md      1:00 既存記事の改善。変更前後を残す
  held.md             保留したもの、退避した未コミット分
  maintain.md         5:00 点検と内部リンク、楽天の適用件数
  report.md           7:00 Slack に流した報告の全文
  status-<枠>.json    枠ごとの実行結果（コミット・所要時間・打ち切りの有無）
```

## 日付の決め方

フォルダ名は**12時間戻した日付**。23:00 の枠と翌朝 7:00 の枠が同じ夜として
1つのフォルダに入る（`scripts/lib/night.ts`）。カレンダー日付で切ると、
23:00 の分析だけ別フォルダに落ちて、次の枠が読めない。

## なぜコミットするか

次の夜の枠が前の夜の記録を読む。とくに `improve-log.md` は、改善前後を
あとで数字と突き合わせるために要る。2〜3週間ぶん溜まると「どの直し方が
効いたか」が見えるので、効いた型を優先できる。

ローカルに置くだけだと別のPCから読めず、効果測定が続かない。
