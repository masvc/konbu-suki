# 指示の受け口

ここに書かれたことを、夜間の各枠が**いちばん先に**実行する。
`docs/next-actions.md` や `docs/topic-map.md` より優先する。

## 書き方

- 1項目1行。`- [ ] ` で始める
- 済んだら `- [x] ` にして、何をしたかを1行添える
- CLAUDE.md のルール（出典・健康・DB書き込み）より優先はしない。
  抵触する指示は実行せず、理由を添えて `- [!] ` にする

## 入れ方

1. このファイルを直接書く（手元・GitHub のどちらでもよい）
2. Slack から入れる → `npx tsx scripts/slack-inbox.ts`（設定は下記）

Slack から取り込むには `.env` に次の2つが要る。webhook（送信専用）とは別物で、
読み取りにはボットのトークンが必要になる。

- `SLACK_BOT_TOKEN` — `xoxb-` で始まるボットトークン。
  必要なスコープは `channels:history`（公開チャンネル）、
  `groups:history`（非公開）、`im:history`（DM）のうち使うもの
- `SLACK_INBOX_CHANNEL` — 取り込み元のチャンネルID（`C` または `D` で始まる）

未設定のあいだは、このファイルを直接書く運用で回る。
