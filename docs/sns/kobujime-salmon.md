# サーモンの昆布締め【1cm幅に切って一晩・刺身用を使う】

https://konbu-suki.com/guide/kobujime-salmon

投稿はしていない。ここから選んで使う。

## 案1

```
サーモンの昆布締めは、柵のまま締める鯛やヒラメと違い、先に１cm幅に切ってから昆布に挟む。塩・黒コショウをふり、湿らせた昆布に並べ一晩おく。サーモンは刺身用のサクを使う。

https://konbu-suki.com/guide/kobujime-salmon
```

## 案2

```
サーモンはアニサキスが寄生する魚の一つ。昆布締めに使う酢や塩ではアニサキス幼虫は死滅しない。家庭でサーモンの昆布締めを作る際は、「刺身用」のサクを使う。

https://konbu-suki.com/guide/kobujime-salmon
```

## 案3

```
昆布締めを作る際、魚の種類で迷うことはないだろうか。サーモンの昆布締めは、鯛やヒラメとは異なり、柵のままではなく１cm幅に切ってから昆布に挟む。冷蔵庫で一晩おくと完成する。
```
