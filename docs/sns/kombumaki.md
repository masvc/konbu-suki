# おせちの昆布巻きの作り方【日高昆布で鮭を巻き、約80分煮る】

## 案1

```
おせちの昆布巻きは、水でもどした昆布で具を巻き、先にやわらかく煮てから味を入れます。日本昆布協会の鮭レシピでは、日高昆布を約50分煮て竹串が通ったら調味料を加え約30分煮ます。「養老昆布」は不老長寿の縁起物です。
```

## 案2

```
昆布巻きを煮る際、酢を少し加えると昆布がやわらかく仕上がります。富山の昆布巻きレシピでも、水から煮て酢を加えています。昆布は煮ると膨らむため、かんぴょうはきつく結びすぎないのがコツです。
```

## 案3

```
昆布巻きの煮込み時間はレシピで違いがあり、どれくらい煮るか迷うかもしれません。初めて作るなら、「竹串がすっと通るか」を目安にするのが確実です。先にやわらかくしてから味を入れます。
```
