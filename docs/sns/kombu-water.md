# 昆布水の作り方【水1.5Lに昆布20g・3時間以上の早見表】

## 案1

```
昆布水の作り方です。水1.5Lに昆布20g程度を3時間以上（できれば一晩）浸けて置くだけ。火を使わないので、鍋も火加減も要りません。冷蔵庫で1週間保存が可能。

https://konbu-suki.com/guide/kombu-water
```

## 案2

```
昆布水を作る際、昆布を水洗いしていませんか。日本昆布協会によると、水洗いすると旨味成分が流れ出てしまうため、固く絞った布で拭くのが良いそうです。水1.5Lに昆布20gで3時間以上漬けて作ります。

https://konbu-suki.com/guide/kombu-water
```
