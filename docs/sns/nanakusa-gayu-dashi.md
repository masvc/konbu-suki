## 案1

```
七草がゆは昆布とかつおのだしで炊き、塩で味を調えます。香川県の資料にある作り方は、だし汁3カップ（600mL）にご飯茶碗3杯を入れ、野菜を加えてひと煮立ちさせます。昆布の量は600mLに対し6〜12gが目安です。
```
