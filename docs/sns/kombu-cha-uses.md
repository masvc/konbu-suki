## 案1

```
昆布茶は料理の調味料として、「和える」「炒める」「溶かして混ぜる」の3つの使い方がある。日本昆布協会のレシピでは、1〜4人分に小さじ1/2〜2が目安。塩分が高いため、他の調味料は控えめに調整すると良い。

## 案3

```
