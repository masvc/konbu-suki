## 案1

```
とろろ昆布とおぼろ昆布は、昆布を削る場所が違います。とろろ昆布は重ねた昆布の側面を削ったもの、おぼろ昆布は昆布一枚の表面を削いだものです。削り方が異なるため、形や使い方も変わります。
```

## 案2
