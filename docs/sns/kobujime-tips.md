# 昆布締めの失敗とコツ【水っぽい・硬い・しょっぱいの原因別対処表】

## 案1

```
昆布締めの失敗原因は「昆布の戻しすぎ」「挟む置きすぎ」「振る塩」の3つ。昆布は水に浸けず濡れ布巾で拭き、時間は厚みで調整、塩は少なめから始めると良い。締まりすぎとしょっぱさは後から戻せない。

## 案2

```
昆布締めはアニサキスを死滅させない。食酢、塩漬け、醤油、わさびでもアニサキス幼虫は死滅しない。サバ、ヒラメ、イカなど寄生が見られる魚を昆布締めにしても、安全処理にはならない。
