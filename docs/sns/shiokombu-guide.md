# 塩昆布の選び方と使い方【2タイプの違いと食材別の組み合わせ】

## 案1

```
塩昆布には「塩昆布」と「乾燥塩吹き昆布」の2タイプがあります。どちらもだし用昆布より塩分が高く、100gあたり18.0g。素干しまこんぶの約3倍です。少量で味が決まりますが、入れすぎると塩辛くなります。

https://konbu-suki.com/guide/shiokombu-guide
```

## 案2

