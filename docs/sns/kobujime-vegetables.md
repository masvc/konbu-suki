## 案1

```
野菜の昆布締めは、水で固めにもどした昆布2枚に、塩を振った野菜を挟み、冷蔵庫へ。酢も重石も不要です。生で食べられる野菜は切って挟むだけ。火を通して食べる野菜は先に茹でます。漬け時間は一晩から一日です。
```
