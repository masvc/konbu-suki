昆布締めは、何も付けずにそのまま食べられる。ポン酢、カルパッチョ、握り、丼にも合う。締めに使った昆布は、細切りにして添える、揚げ物、煮物やだしに回す。

## 案2

```
昆布締めに使った昆布は捨てません。細切りにして料理に添える、衣をつけて揚げる、煮物やだしに回す。日本昆布協会のエコレシピに使い道が載っています。

## 案3

```
昆布締めの味が薄いと感じても大丈夫。盛り付けてから塩を振って調えられます。締める前の塩を控えめにしておけば、ポン酢やわさび醤油など後から合わせる調味料で調整できます。
