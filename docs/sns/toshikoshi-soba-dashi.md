# 年越しそばのだし【定番のつゆに昆布は入っていない・足すなら何g・手順】

https://konbu-suki.com/guide/toshikoshi-soba-dashi

投稿はしていない。ここから選んで使う。

## 案1

```
定番の年越しそばつゆに昆布は入っていません。削り節だけ。足すなら水1Lに昆布10〜20gから。昆布を30分漬けて沸騰前に取り出し、削り節を入れます。事実と提案を分けて解説。

https://konbu-suki.com/guide/toshikoshi-soba-dashi
```

本文 86字（案1は「農林水産省の資料から解説」を差し替えた。昆布を足すのは当サイトの提案で、農水省の資料ではないため） / URL込み 111字

## 案2

```
定番の年越しそばつゆに昆布は入っていません。農林水産省の資料では削り節50g（水1L）で出汁を取ります。昆布と鰹節のうま味相乗効果も。昆布を足す場合の目安と手順を紹介します。

https://konbu-suki.com/guide/toshikoshi-soba-dashi
```

