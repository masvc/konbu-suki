## 案2

```

## 案3

```
昆布だしと鰹だしの使い分けに迷うことはありませんか。潮汁・精進料理・すし飯には昆布だし。吸い物・清し汁・茶碗蒸しには鰹一番だし、または昆布と鰹の混合だしが適しています。うま味成分や取り方も異なります。
