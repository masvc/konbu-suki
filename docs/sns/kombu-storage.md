昆布の保存方法は、湿気を避けて乾燥した場所に置くのが基本です。日本昆布協会によると、常温でも冷蔵庫や冷凍庫でも構いません。どこに置くかよりも、湿気を入れないことのほうが重要です。密閉できる容器や袋を使用します。

## 案2

```
昆布の表面の白い粉はカビではなく、マンニットという旨み成分です。日本昆布協会は、水洗いすると旨み成分が流れるため、固く絞った濡れぶきんでさっと拭くことを推奨しています。緑や黒の斑点、べたつき、かび臭いにおいは湿気を吸った兆候です。

## 案3

```
乾燥昆布を長いまま袋に戻すと、口が閉まらず湿気が入ることがあります。日本昆布協会は15cmくらいの長さに切って缶やビンに入れ、密閉保存することを推奨しています。こうすると、だしを取る際に計りを使わず枚数で量を決められます。
