## 案1

```
昆布だしの基本の取り方は、水1Lに昆布10～20gを30分漬け、中火にかけ沸騰直前で取り出す。水出しは水1.5Lに昆布20gを3時間以上漬ける。どちらも水洗いせず拭いて使う。

https://konbu-suki.com/guide/how-to-make-dashi
```
