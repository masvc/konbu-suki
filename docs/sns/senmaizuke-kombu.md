## 案1

```
千枚漬けは、薄切りのかぶを塩で一昼夜、昆布と甘酢でもう一昼夜漬けて作ります。農水省のレシピでは、聖護院かぶ1kgを2mmに切り塩20gで一昼夜漬け、水気を切って昆布45gと甘酢を注ぎ、さらに一昼夜おきます。京都の郷土料理です。

https://konbu-suki.com/guide/senmaizuke-kombu
```

## 案2

```
千枚漬けは、長期保存を目的とせず、繊細に漬け上げられます。また、千枚漬けと呼ばれる料理は京都だけでなく、青森県にも「赤かぶの千枚漬け」があります。昆布の量や切り方、漬ける時間がそれぞれ異なります。
```
