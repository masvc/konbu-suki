# ヒラメ・白身魚の昆布締め【塩5分・半日の目安】

## 案1

```
ヒラメの昆布締めは、塩を振って5分、酢で湿らせた昆布に挟んで半日が目安時間です。工程は、塩を振る、昆布を酢で湿らせる、挟んで冷蔵庫に入れる、そぎ切りにするの4つです。初めて作るなら半日から試すほうが戻しやすいです。

```

## 案2

```
富山ではカジキマグロが定番の昆布締めですが、シロエビやホタルイカも使われています。魚の切り身に限られるものではありません。刺身用であれば昆布締めとして作れます。初めて作るなら半日から試すほうが良いです。

## 案3

```
昆布締めの魚ごとの時間で困ることはありませんか。魚ごとの時間を示した出典は見つかっていません。ヒラメは半日が目安です。別の魚で作る時は厚みの近いものから時間を当て、初めてなら半日から試すほうが戻しやすいです。
