# 松前漬けの作り方【農水省のレシピの分量・1週間の漬け込み・正月に間に合う仕込み日】

https://konbu-suki.com/guide/matsumaezuke

## 案1

```
松前漬けは、するめいかと昆布を醤油・みりん・酒で1週間漬け込む北海道の郷土料理です。農水省のレシピでは、スルメイカ1枚、昆布60cmなど。正月料理として元日に食べるなら12月25日ごろに漬け始めます。
```
