# 鯛の昆布締め【塩小さじ1/2で10分・柵のまま一晩】

https://konbu-suki.com/guide/kobujime-tai

投稿はしていない。ここから選んで使う。

## 案1

```
鯛の昆布締めは柵のまま締めます。日本昆布協会のレシピでは、柵200gに塩小さじ1/2を振り10分、昆布で包み冷蔵庫で一晩（8時間弱）置くとあります。塩の分量まで書かれた目安は少ないです。

https://konbu-suki.com/guide/kobujime-tai
```

## 案2

```
鯛の昆布締めに使う昆布の種類は指定されていません。日本昆布協会は「鯛の長さに合わせた」昆布としています。羅臼昆布が挙げられる一方、江戸前寿司職人は「風味が強すぎる」と日高昆布を使うこともあります。

## 案3

```
鯛の昆布締め、塩加減に迷いませんか。柵200gに塩小さじ1/2が目安です。切り身は塩が当たる面が増えるため、柵の分量をそのまま使うとしょっぱくなりやすくなります。足りなければ後から足せます。
