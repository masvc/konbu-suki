## 案1

```
クーブイリチーは、千切りの昆布を油で炒め、豚だしで煮汁がなくなるまで煮る沖縄の郷土料理です。農水省のレシピでは昆布40g、豚三枚肉60gを使用します。昆布と「よろこぶ」をかけて祝い事にも欠かせない一品です。

https://konbu-suki.com/guide/kubu-irichi
```
