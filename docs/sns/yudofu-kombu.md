# 湯豆腐の昆布【水1Lに10〜15g・前の晩に昆布水・昆布は鍋に敷いたまま】

## 案1

```
湯豆腐の昆布は、水1Lに10〜15gの昆布で昆布水を前の晩に作り、その昆布を鍋に敷いたまま煮る。日本昆布協会では1晩（10時間位）冷蔵庫で寝かせた昆布水を使う。利尻昆布、羅臼昆布、真昆布が昆布水に向く。

```
