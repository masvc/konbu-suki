# 海外向けの準備

2026-11-15 作成。**調べた結果、いま英語記事や海外発送に手を広げるのは勧めない。**
理由と、やるとしたら何が要るか、いつ始めるかの基準をここに置く。

結論を先に書くと

1. **海外からの読者は、まだ来ていない。** 来ているように見えるのはクローラー
2. **海外発送（食品の輸出）は、個人サイトの手に負えない関門がある**（FDA登録・
   HACCP・相手国ごとの証明書）。やるなら自分で送らない形にする
3. いま効くのは日本語の記事と導線。**海外は「測る仕組み」だけ置いて待つ**

## 2. 海外発送（食品の輸出）に何が要るか

調べて分かった関門。**どれも個人で越えるには重い。**

### 共通：相手国ごとに「送れるか」が違う

国際郵便は、あて先の国・地域ごとに禁制品が決まっている。食品は国によって
扱いが分かれ、**EMSでは食料品がすべて禁止の国もある**（フランス）。
送る前に国・地域別情報（国際郵便条件表）で1か国ずつ確認する必要がある。

- 日本郵便「送れるもの・送れないもの」
  https://www.post.japanpost.jp/int/ems/ryugaku/know/index.html
- 日本郵便「国・地域別情報（国際郵便条件表）」
  https://www.post.japanpost.jp/cgi-kokusai/country_jp_list.php

### 米国：FDAの登録と事前通知、水産物HACCP

昆布は水産物にあたるので、米国向けは水産物の枠で見る。

- **FDAの食品施設登録**（バイオテロ法）。米国内外で食品を製造・加工・梱包・
  保管する施設は登録が義務。食品安全強化法により**偶数年の10月1日〜12月31日に
  更新**が必要
- **事前通知**。航空便は到着4時間前、船便は8時間前までにFDAへ提出
- **水産物HACCP**。21 CFR Part 117 のCGMPに従った衛生管理に加え、
  水産物を加工する製造業者は 21 CFR Part 123 によりHACCPプランに従う必要がある
- FSMA第106条「意図的な食品不良の防止（食品防御）」への対応も必要

出典：JETRO「水産物の輸入規制、輸入手続き（米国）」（調査時点2024年1月）
https://www.jetro.go.jp/world/n_america/us/foods/exportguide/marineproducts.html

### 中国：産地証明と放射性物質検査証明、施設登録

- 福島・宮城・茨城・栃木・群馬・千葉・東京・埼玉・新潟・長野の**10都県は
  全ての食品・飼料が輸入停止**
- 水産物は、2025年6月29日に**37道府県産の輸入停止が解除**された。ただし
  **産地証明書**（10都県以外で生産されたことの証明）と**放射性物質検査証明書**
  （輸出ロット毎）の添付が条件
- **水産物の輸出には、加工・保管・包装施設および養殖場の登録が必要**

出典：農林水産省「中国の輸入規制の概要（2025年6月29日以降）」
https://www.maff.go.jp/j/export/e_shoumei/attach/pdf/china_shoumei-16.pdf

### そのほかの国

東日本大震災に伴う放射性物質の輸入規制は、EU・英国・スイス・インドネシア・
台湾など多くの国・地域で撤廃されている（台湾は2026年11月21日に撤廃を公表）。
**規制の有無は国ごとに動くので、送る時点で農林水産省の輸出関連ページを見る。**

- 農林水産省「アジアにおける規制措置の変遷」
  https://www.maff.go.jp/j/export/e_shoumei/oshirase/asia.html

### ここから言えること

**自分で小口の海外発送をやる形は、現実的ではない。** やるとしたら

- すでに輸出の体制を持っている事業者の商品を紹介する（アフィリエイトの延長）
- 海外発送に対応している通販事業者へ送客する
- こんぶBOXを海外に出すなら、**輸出できる加工業者と組む**（自分で製造・
  梱包・保管しない）

いずれも「自分で送らない」のが要点。いまのこんぶBOXは配送先を日本のみに
しているので、その前提は変えない。

## 3. いまやること・やらないこと

### やること（置いた）

- **`scripts/overseas-demand.ts`** — 海外からの需要を測る。国別のエンゲージ
  セッションと平均滞在でクローラーと読者を分け、Search Console の非日本語
  クエリを数える。**「国別のユーザー数」だけを見て判断しないため**に作った
- このファイル（調べた関門と出典を残して、同じ調べ直しをしないため）

### やらないこと（いまは）

- **英語記事を書く** … 日本語でも見つかっていない段階で記事が倍になる。
  非日本語クエリは90日で0件
- **hreflang や /en のルート** … 英語のページが無いうちは入れるものが無い。
  Next.js 側の作りは後から足せる（いま決めておく必要が無い）
- **海外発送の対応** … 上の関門。こんぶBOXは日本のみのまま

## 4. 始める基準（これを超えたら動かす）

`scripts/overseas-demand.ts` が最後に出す2つの数字で決める。

| 指標 | 基準 | いま（90日） |
| --- | --- | --- |
| 日本以外のエンゲージセッション | 50以上 | **4** |
| 非日本語クエリの表示回数 | 200以上 | **0** |

どちらかを超えたら、次の順でやる。

1. **いちばん読まれている記事1本だけ**を英語にして様子を見る
   （全部ではなく1本。umami / dashi / kombu のどれで来ているかを先に見る）
2. そのページに hreflang を入れる（日本語版と相互に）
3. 英語で来た人が何を探していたかを Search Console で見てから2本目を決める

**先に増やさない。** 1本で反応が無ければ言語の問題ではない。

| 項目 | 聞くこと |
