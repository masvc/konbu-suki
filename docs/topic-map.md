## 記事の型（CLAUDE.md のコンテンツ方針に従う）

1. 冒頭2〜3行で結論を言い切る（AI検索はここを拾う）
2. 比較表 or 早見表（表はそのまま引用されやすい）
3. 本文
4. FAQ 3〜5問（FAQPage の構造化データになる）
5. 関連記事への内部リンク。`src/lib/guides.ts` の `related` に話題の近い slug を
   3本書く。**書き忘れると記事末尾が先頭4本の固定になる**（`site-check.ts` が
   warn で出す）。本文中でも関連記事のタイトルに触れる
