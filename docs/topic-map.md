## 出典に使わない資料

内容が正しそうに見えても、次のものは出典にしない。

| 資料 | 理由 |
| --- | --- |
| 昆布メーカーの解説コラム | 出典の記載が無く、数値が自社調査のことがある。実際に見たページでは、うま味の相乗効果の倍率が「自社調査」の注記つきで、裏を取る先が無かった。編集方針で「実際に開いて内容を確認した資料だけを使う」と公開している以上、確認先が無いものは使えない |
| レシピ系メディア | 同上。手順の裏付けが取れない |

話題を見つける目的で読むのは構わない。**書くときは一次資料に当たり直す。**
メーカーの解説で出てきた事実は、公的機関・業界団体の資料で同じことが
確認できたときだけ書く。
