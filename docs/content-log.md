| 出典 | 日本昆布協会「昆布の種類」、北海道 水産林務部「ガゴメ（篭目）」（いずれも WebFetch で確認済み） |
| 商品リンク | searchKeyword「がごめ昆布」経由の CTA |
| 状態 | **公開** |

**出典にある記述を意図的に1つ落とした。** 北海道のページには「ガゴメの特徴である
粘りやぬめりの主成分には、抗がん作用が確認されている『フコイダン』がマコンブの
約2倍含まれ」とある。このうち「抗がん作用が確認されている」は使っていない。
CLAUDE.md のコンテンツルール（効果効能を断定しない・「予防」「治る」等の断定表現を
使わない）に反するため。行政のページにある記述でも、商品リンクが並ぶページに
そのまま置けば効能の訴求になる。

フコイダンが真昆布の約2倍という含有量の記載だけは残した。これは成分の事実記載で、
ルールが認めている範囲にあたる。

ヨウ素の注意を独立したセクションとFAQに入れた。この記事は栄養の記事ではないが、
がごめ昆布はだしを取るのではなく昆布そのものを食べる使い方が中心になるため、
摂取量の注意が必要な対象にあたると判断した。

ぎょれんにがごめ昆布の記載が無いことは topic-map に記録済みだった。協会の種類
ページに記載があることが分かったので、そちらを出典にしている。

アイキャッチは生成済み（1200x675 WebP 189KB）。

| 出典 | 日本昆布協会「昆布の種類」、農林水産省「にっぽん伝統食図鑑」とろろ昆布・おぼろ昆布、北海道ぎょれん（すべて WebFetch で確認済み） |
| 商品リンク | searchKeyword「とろろ昆布」経由の CTA |
| 状態 | **公開** |

協会の定義が「側面を削る」「表面を削る」と書き分けているため、そこを記事の軸に
した。味や産地から説明すると差が伝わらないが、削る場所の違いなら一文で済み、
形と使い方の違いもそこから説明できる。

削ったあとに残る芯が白板昆布（ばってら昆布）になることも入れた。3つが同じ加工の
流れから出てくることは、個別の商品説明からは見えない。

味の優劣には触れていない。どちらが上かを示した出典が無いため、形で選ぶという
書き方にした。

「縄文時代から日本人に食されてきたと言われています」と断定に近い形だった。

## 記録の付け方

記事ごとに上の表の項目を埋める。状態は「公開」か「保留」。
保留にするときは `保留: 理由` の行を書く。2時間ごとの作業報告がこの行を拾って
「朝やること」に出す。
